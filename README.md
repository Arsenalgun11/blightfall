# Blightfall — multiplayer server pack

[Blightfall 3.1.1-CE](https://www.technicpack.net/modpack/blightfall.592618) (Minecraft 1.7.10)
set up for Adam's Blightfall server: you crash-landed on a planet eaten by the Taint.
Thaumcraft, Tinkers' Construct, Blood Magic, Botania, Thermal Expansion and a huge
Hardcore Questing storyline. Survive, push the blight back, keep Mission Outlook up.

**Server address:** `ADDRESS_TBD` — already in your multiplayer list after import.

## Install (4 steps)

1. Install [Prism Launcher](https://prismlauncher.org/download/) (free). It downloads the
   right Java (Java 8) by itself.
2. In Prism: **Add Instance → Import**, and paste this link into the box:

   ```
   https://github.com/Arsenalgun11/blightfall/releases/download/v1.0.0/Blightfall-Server-1.0.0.zip
   ```

   (or download the zip from the [Releases page](https://github.com/Arsenalgun11/blightfall/releases/latest)
   — it's under **Assets** — and pick the file with **Browse**). Click **OK**.
3. Launch **Blightfall (server)**. Log in with the Microsoft account that owns
   **Minecraft: Java Edition**.
4. **Multiplayer → Blightfall → Join Server.**

Before you can join, send Adam your exact Minecraft username so he can whitelist you.

The server sleeps when nobody is on. If it says it's starting, wait about two minutes and
join again.

See [INSTALL.md](INSTALL.md) for troubleshooting.

## What's in the zip

Blightfall 3.1.1-CE exactly as the Technic pack ships it (mods, configs, scripts,
resource pack), set up as a Prism instance: Minecraft 1.7.10, Forge 10.13.4.1614, 6 GB of
RAM, and the server pre-added. Nothing is added or removed from the pack's mod list.

`build_pack.py` is how the zip is made (from a Prism install of the Technic pack).
